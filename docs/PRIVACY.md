# Politique de confidentialité — HeicDrop

*Dernière mise à jour : 11 novembre 2026*

HeicDrop est une application de conversion d'images qui fonctionne **entièrement sur votre ordinateur**.

- **Aucune donnée personnelle n'est collectée**, stockée ni transmise par HeicDrop.
- **Aucune connexion Internet** n'est utilisée : vos images ne quittent jamais votre ordinateur.
- **Pas de publicité, pas de télémétrie, pas de statistiques d'utilisation**, pas de compte utilisateur.
- L'application lit uniquement les fichiers que **vous** lui donnez (glisser-déposer ou sélection) et écrit les images converties dans le dossier que **vous** choisissez.
- Les seules informations conservées localement sont vos préférences (dernier format choisi, dernier dossier de destination), enregistrées dans le dossier de configuration de l'application sur votre ordinateur. Désinstaller l'application les supprime.
- Les métadonnées présentes dans vos photos (date, appareil, position GPS…) sont recopiées dans les fichiers convertis, sur votre ordinateur uniquement.

Le code source de HeicDrop est public (licence MIT) et peut être vérifié par tous.

Pour toute question : ouvrez une demande (*Issue*) sur le dépôt GitHub du projet.

# Privacy Policy — HeicDrop (English)

HeicDrop runs **entirely on your computer**. It collects **no personal data**, uses **no network connection**, contains **no ads, telemetry or analytics**, and requires no account. It only reads the files you give it and writes converted images to the folder you choose. Your preferences (last output format and folder) are stored locally and removed on uninstall. The source code is public under the MIT licence.
